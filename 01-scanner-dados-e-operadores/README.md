### 01. Scanner, Dados e Operadores 📥

#### 🎯 O que é abordado neste módulo
Nesta etapa inicial, o foco é entender a interação com o usuário através do console, entrada/saída de dados e manipulação de variáveis com operadores matemáticos e lógicos.

#### 💡 Conceitos Aplicados
- Leituras de console utilizando a classe `java.util.Scanner` (`nextLine()`, `nextInt()`, `nextDouble()`).
- Declaração de variáveis e tipos primitivos (`int`, `double`, `boolean`, `String`).
- Operadores aritméticos (`+`, `-`, `*`, `/`, `%`) e de atribuição.
- Boas práticas com fechamento de recursos (`scanner.close()`) e limpeza de buffer.
